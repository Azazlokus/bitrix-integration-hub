# PHP-код

- Каждый файл начинается с `<?php` и `declare(strict_types=1);` (исключение — файлы, которые Битрикс подключает как шаблоны/`.settings.php` и где это ломает поведение; тогда комментарий почему).
- PSR-12, `final` по умолчанию для классов, `readonly` для DTO/VO, конструкторное внедрение зависимостей, без статических синглтонов собственного кода.
- Типы везде: параметры, возвраты, свойства. `mixed` и `array` без shape — только с PHPDoc `@param array{...}` / `list<...>` для PHPStan.
- Исключения: свои доменные классы в `Domain\Exception`, не глушить `\Throwable` без логирования.
- Никаких `eval`, `extract`, `unserialize` недоверенных данных, `$_GET/$_POST` напрямую — только `Bitrix\Main\Context::getCurrent()->getRequest()`.
- SQL — только через ORM/`SqlHelper`, никакой конкатенации пользовательского ввода.
- Вывод в шаблонах — через `htmlspecialcharsbx()` / экранирование по контексту.
- После правки файла хук запускает `php -l`; перед коммитом прогони `make lint` и `make stan` (после этапа 1).
