# Тесты

- `tests/Unit` — без Битрикса, быстрые: маппинги, подписи HMAC, расчёты, ретраи, state-машины статусов.
- `tests/Integration` — бутстрап Битрикса (`tests/bootstrap.php` → `prolog_before.php` с `NO_KEEP_STATISTIC`, `NOT_CHECK_PERMISSIONS`), каждый тест в транзакции с откатом.
- `tests/Contract` — контракты к mock-services; для Б24 — фикстуры реальных ответов API в `tests/Fixtures/b24/` (обезличенные!).
- Внешние системы в тестах — только моки/фейки. Сеть наружу из тестов запрещена.
- Имена: `test<Что>_<При каком условии>_<Ожидание>` или `#[Test]` + описательное имя.
- Каждый баг-фикс — сначала падающий тест.
