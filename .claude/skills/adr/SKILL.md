# ADR: $ARGUMENTS

1. Найди следующий номер: `ls docs/adr/ | grep -E '^[0-9]{4}-' | sort | tail -1`.
2. Создай `docs/adr/NNNN-<kebab-case-title>.md` по шаблону `docs/adr/template.md`.
3. Заполни честно: контекст, **минимум 2 рассмотренные альтернативы** с плюсами/минусами, решение, последствия (включая негативные). Для библиотек укажи проверенную актуальную версию и дату проверки.
4. Статус `Proposed`, пока пользователь не согласился; затем `Accepted`. Заменённые ADR — `Superseded by NNNN`.
5. Добавь ссылку в индекс `docs/adr/README.md`.
6. Коммит: `docs(adr): add NNNN <title>`.
